# A5 · 源码 verify 与「怎么复现同一份字节码」（2026-10-11）

## 一句话

`scan.botchain.ai` 从国内**连不上**（本机 2026-10-11 实测：不走代理 `TCP 443` 不通、HTTP `000`；走代理也不行 —— Clash 端口 7890 当时没开），
所以「在浏览器上提交 verify」这一步当时做不了，按 `02-作战与答辩/赛后优化-二人方案-2026-10-11.md` A5 的兜底走：
**导出 flatten 源码 + 编译参数 + sha256 清单**，放进 `03-合约/`。

两个部署件（`RainDeliveryInsuranceV3.sol`、`OperatorMultisig.sol`）**都不含 `import`** ⇒ 源文件本身就是 flatten 结果，
所以这里**没有另存一份 `.flat.sol` 副本**：两份源码早晚会漂移，保留一份才是对的。
（2026-10-12 起，门禁把 `RainDeliveryInsurance.sol`（v1）与 `RainDeliveryInsuranceV2.sol` 也一起重编核对 —— 四个 `.sol` 同样都不含 `import`，各自的哈希在 `03-合约/verify-manifest.json`；下表仍只列 677 上这两个部署件，因为 A5 要 verify 的是它们。）

## 怎么复现（一条命令，自己断言）

```powershell
cd 07-测试工具
npm run compile                # v1（无 --via-ir）
npm run compile:v2             # v2（--via-ir）
npm run compile:v3             # = node compile_sol.js ../03-合约/RainDeliveryInsuranceV3.sol --via-ir
npm run compile:multisig       # 多签
node make-verify-pack.js     # 重新编译四个部署件 → 打印全部哈希 → 写 03-合约/verify-manifest.json
```

`make-verify-pack.js` 自己断言 16 项（每个合约 4 项 × 4 个合约，2026-10-12 前只有 2 个合约 = 8 项）：编译器 0 error、源文件无 `import`（否则「单文件即 flatten」不成立会报错）、
盘上 `.bytecode.txt` 与本次重编**逐字节**一致（防产物过期）、运行时长度 = 链上实测长度。任一项对不上就**非零退出**。
刚才跑：**0 项失败，exit=0**（solc `0.8.37+commit.f401782d.Emscripten.clang`）。

## 还差的那一次比对（不装懂）

- **已证**：本地源码 → solc 0.8.37（optimizer 200 / paris / viaIR）→ 运行时 **15,823 B**、keccak `0x68cf9c8d…`；
  链上 2026-10-08 用 `eth_getCode` 量到的运行时长度也是 **15,823 B**。
- **未证**：链上那 15,823 字节的**逐字节**内容。差的只是「再连一次主网取 code、算 keccak 对比」，代理在时一条命令的事：
  ```powershell
  $env:HTTPS_PROXY='http://127.0.0.1:7890'; $env:NODE_USE_ENV_PROXY='1'
  node D:\DSH\_tmp\verify677.js      # 只读探针：回执 + 代码长度 + 全部 getter
  ```
  取回后与上表的运行时 keccak 比：**相等 ⇒ 主网那份 code 就是这份源码编出来的**，verify 这件事在链下也自证完了。
- 顺带说清一件：`05-演示站点/frozen-node.js` 里烘的那份 code 也是 15,823 B、keccak 同样 `0x68cf9c8d…`，
  但它是 `make-frozen-node.js --rebuild` **从编译产物重建**的，只能算「快照与源码一致」，**不算链上独立证据**。
