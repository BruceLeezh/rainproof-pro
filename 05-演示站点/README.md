# 演示站点怎么看（05-演示站点）

本目录只有四个文件，没有构建步骤：`index.html`（V4 单页演示）、`verifier.html`（核验台，只读 rpc 视图）、
`ethers.umd.min.js`、`frozen-node.js`（页面自带的 677 离线快照）。
本文只讲「怎么看、数据是哪来的」；真链教程与链上地址仍以根目录 `README.md` 的 §2「连真链」、§3「链上地址」为准（那两节没有搬动）。

## 30 秒上手

- **单文件离线双击即可打开**：`index.html` 引的 `ethers.umd.min.js` 与 `frozen-node.js` 都是同目录本地文件，不联网取脚本。
- **只读浏览不需要钱包**：看板、资金池余额、事件流、核验台打开就看，数据是页面现读链上。
- 要现场投保 / 注资才需要 MetaMask，且**要走 HTTP 服务**（`file://` 页面下钱包不注入），网络没加过时页面会自己调 `wallet_addEthereumChain` 帮你加 677。

## 页面 V4 的 hash 路由

路由表在 `05-演示站点/index.html:2674-2681`，只做一件事：把 hash 变成 `body[data-page]`：

| hash | 页面 |
|---|---|
| `#home` | 首页（不带 hash 打开会自动补上） |
| `#dashboard` | 降雨量测看板 |
| `#insure` | 开一张保单 |
| `#mypolicy` | 我的保单 |
| `#ops` | 合约配置与运营 |
| `#notes` | 只读模式与诚实说明 |

- 导航高亮、`document.title` 都跟着 hash 走；`#dashboard#anchor` 这类写法只取第一段；浏览器前进 / 后退即 hashchange（`index.html:2691-2740`）。

## 它读哪条链：四层回退

候选节点按优先级排（`05-演示站点/index.html:1340-1345`）：

1. `https://rpc.botchain.ai` —— **BOT Chain 主网 677**，v3 是现行演示基线；
2. `https://rainproof-juice-68d3.vercel.app/api/rpc` —— Vercel 上的只读中转（机房直连主网）；
3. `https://rpc.bohr.life` —— **测试网 968**，v2 那 6 张已赔保单的留痕；
4. `05-演示站点/frozen-node.js` —— 页面自带的 **677 离线快照**。

- 前三条是**并行阶梯**：第 1 条先出发，其余每条晚 1.2 秒，`Promise.any` 取最先应答的那条 —— 既保留优先级，又不会为一个连不上的节点白等 8 秒（`index.html:1513-1531`）。
- **三层节点全挂**才会落到第 4 层快照；`?snap=0` 关掉兜底，`?snap=1` 强制只看快照（现场不赌网络）。
- `?rpc=<你确信可达的节点>` 可临时指定节点（本地假链联调也用它）。

## 怎么判断当前数据来自直连 / 代理 / 968 / 快照

看这五处，页面每个层级都如实标出，不假装实时：

| 看哪里 | 显示 | 含义 |
|---|---|---|
| 顶部右侧链名（`#netText`） | `BOT Chain Mainnet` | 真链（直连或中转，看页脚 URL） |
| | `… · 链上快照` | 第 4 层，离线快照 |
| | `本地假链（非 …）` | chainId 被伪装，见红色横幅 |
| 顶部**金色横幅** `frozenBar` | `⚠ 链上快照：按网址参数 ?snap=1 强制…` 或 `…三层节点都连不上…`，并带 `capturedAt` 时间 | 是快照，且属于两种原因中的哪一种（`index.html:1546-1559`） |
| 顶部**红色横幅** `fakeChainBar` | `⚠ 当前连的是本地假链（块高 …，chainId 被伪装成 …）` | 判据是「chainId 对得上、块高却太小」：真链已 2500 万+，本地假链从 0 开始（`MIN_REAL_BLOCK`，`index.html:1347-1349`）；此时投保 / 注资锁死 |
| 页脚节点名（`#footNode`） | 实际连上的 URL；快照时写「链上快照（离线文件 frozen-node.js）」 | 一眼看出走的是直连、中转还是 968 |

退到 968 时页面会**单独 toast 一句**「主网节点在当前网络不可达…已自动切到测试网 968（v2 口径）」（`index.html:1606-1608`），不会让人以为看的是主网数据。

## 677 与 968 的差别（别把两套数字混着讲）

| | 主网 677（现行基线） | 测试网 968（历史留痕） |
|---|---|---|
| 合约 | **v3**：`0x89e7C942535930B61cB61631051E8b0bD670596a` | v2（12,378 字节），不主动连 |
| 链上状态 | 池子现行 0.05105 BOT 等，见根 `README.md` §3 | 池子 0.0643 BOT、6 张保单**全部已赔付** |
| 怎么切过去 | 默认就是 | 加 `?rpc=https://rpc.bohr.life` |

两边的池子、事件、保费网格不是同一套；**演示基线是 677 v3**，968 只作留痕（详见根 `README.md`「主网交付清单（BOT Chain Mainnet · chainId 677）」与 §3）。

## 离线快照是什么、不是什么

来自根 `README.md` §2「连不上主网时：演示页自带的链上快照」，这里只提要：

- 它是节点当时**原始回答的离线复刻**：合约地址、代码长度 15,823 字节、池子 0.05 BOT（快照值；主网现行 0.05105 BOT）、五城累计、两档阈值、10 格差异化保费、8 条事件（含成都拒收）。
- **只覆盖读操作**，不含真字节码回执、不含交易回执；是**某一时刻的读数，不是实时**，不能替代能连主网的节点。
- 文件头部 `meta.note` 写明了取景高度（块 25,950,600）与来源（`rebuild-from-verified-readings`），核对方便。
- 重建 / 核验命令（根 `README.md` §2 原样保留）：`node 07-测试工具/make-frozen-node.js --from-rpc|--rebuild`、`node 07-测试工具/check-frozen-node.js`。

## 现场常见问题

- 国内直连 `rpc.botchain.ai` 需要代理（2026-10-08 实测直连 curl 返回 000）；不想赌网络就加 `?snap=1`。
- 打开是 `file://` 时钱包不注入 —— 只读正常，写操作请起一个本地 HTTP 服务。
- 想自证没在读假链：看块高是否远大于 1,000,000。
- 数据是快照还是实时，别只看数字大小，看金色横幅在不在。
