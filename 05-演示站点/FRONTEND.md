# 雨证前端 · 2026-10-29

当前产品入口为 `insurance.html`；运行 `node 07-测试工具/build-site.js` 后，`site-dist/index.html` 为同一新版首页。源目录的 `index.html` 仍是历史 V3 页面，现有历史核验门禁依赖它。

## 页面与共用层

- `insurance.html`：产品首页、骑手/平台/核验三个角色入口、流程说明、12h/24h 规则切换与 FAQ。
- `rider.html`：骑手保障中心；宽屏为投保与保单双栏，手机依次显示。
- `console.html`：平台控制台，统一指标区、操作区与可横向滚动的数据表。
- `verify-v6.html`：V6 证据核验台，统一连接、通过、失败与等待状态。
- `terms.html`：规则与风险，增加章节目录，链接指向当前 V6。
- `index-v6.html`：技术看板，保留原有 hash 路由、读数与交易处理。
- `styles/site.css`：唯一共用设计令牌、导航、按钮、输入框、状态与响应式规则。
- `styles/landing.css`：产品首页布局和图表示意。
- `styles/{rider,console,verify,terms,dashboard}.css`：从各页原内联样式提取的页面布局。共享规则最后加载。
- `site.js`：移动端导航、Esc 收起、规则切换和报价错误的字号处理，不发起链上交易。

所有字体、图形、CSS 与脚本均为系统或本地资源，没有新增外部 CDN、分析埋点或 npm 依赖。首页图表明确标注为规则示意，不是实时气象数据。

## 本地查看

### 我的城市：三种降雨模式

V6 看板支持同一自选区划切换链上演示、历史气象与实时气象。历史模式保留原五城内嵌快照，自选城市按相同历史区间查询 Archive；实时模式查询最近 12 / 24 小时的完整逐小时降水。两者仅为浏览器对照，不写链，不代替判定或领取条件。

`city-weather.js` 负责坐标解析、逐小时完整性校验、超时、请求去重与按城市/区间缓存；`weather-coordinates.js` 使用既有区域坐标，其他区划按代码查询 DataV 地理边界中的中心点。坐标不可用时明确报错，不使用同名或邻近城市替代。单城市失败保留其他城市，支持显式重试。城市选择不再刷新页面，右栏随当前模式同步。
