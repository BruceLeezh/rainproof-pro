# 雨证 V6 首页设计预览

日期：2026-10-29。交付范围：三套独立首页视觉方向、桌面与手机预览、可交互规则示意、Figma 可编辑结构稿。设计文件只位于 `design-preview/`，没有激活新的首页。

- [方案总览](index.html)：切换桌面 / 手机缩略图，比较三种方向。
- [A 清朗蓝](a.html)：蓝白与浅绿、粗体标题、原创骑手场景。建议作为产品首页方向。
- [B 风雨有温度](b.html)：纸色与森林绿、衬线标题、雨伞插画，突出普惠保障与赛事叙事。
- [C 证据观测站](c.html)：深墨蓝与薄荷绿、细线信息图，适合技术答辩与证据核验。
- [Figma 六张可编辑稿](https://www.figma.com/design/341s2hE0pP6AW9mKIuTtBF?node-id=6-150)：三套桌面与三套手机结构稿，原生文字、矢量插画、组件按钮；没有用整页截图充当设计图层。

## 参考来源与取舍

研究了以下官方站点的首页与信息顺序；此处为设计观察，不构成合作或背书。

| 来源 | 借鉴方法 | 在雨证中的应用 |
| --- | --- | --- |
| [Lemonade](https://www.lemonade.com/) | 面向用户的价值表达、突出主要行动、场景插画 | A 的骑手价值主张与主按钮 |
| [Raincoat](https://www.raincoat.com/) | 气候保护场景、插画与留白 | 天气保护的场景化表达；插画为雨证原创 |
| [Arbol](https://www.arbol.io/) | 自然色系、从问题到机制的逐层叙事 | B 的森林绿与温和排版 |
| [Descartes](https://descartesunderwriting.com/) | 先讲产品价值，再展示技术与数据 | C 的清晰分层与证据入口 |

不引用同行的客户数、合作标识、赔付速度或持牌身份作为本项目能力。页面全部“元”均指模拟展示；示意降雨图不代表实时天气。最高实际模拟给付为 75 元，额度基数为 100 元。时效、判定、置信度与资金等条件仍明确保留。

## 设计与延伸

三套页面均包含：首屏价值主张、骑手 / 平台入口、三步运作说明、12 / 24 小时阈值切换、常见问题、模拟演示披露、可折叠手机导航与键盘焦点。

建议后续采用 A 的产品层级、B 的温和文案与 C 的证据表达，统一骑手表单、平台控制台、核验表格的字号、间距、主按钮和状态标记。当前阶段以选定视觉方向为目的。

`concepts.css`、`concepts.js` 是预览共用样式与交互，`design-tokens.json` 记录三套颜色与字体方向。图片为本地原创 SVG；字体为 Noto Sans SC、Noto Serif SC、Manrope 的文字子集，来源记录与 SIL OFL 许可证放在 `assets/`。预览本身无需远程字体请求。

## 验证
