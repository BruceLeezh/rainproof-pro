雨证 · 只读节点代理 / RainProof read-only RPC proxy

这是一个 Vercel Serverless Function，不是演示页面。它把只读的 BOT Chain JSON-RPC 转发到主网节点， 好让「没有代理」的网络也能读主网 677。
A serverless JSON-RPC relay, not the demo. Endpoint: POST /api/rpc
演示页 / Demo：juice-butterfly.github.io/rainproof
点上面的按钮，或自己打一条：
curl -s <本域名>/api/rpc -H "content-type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'
期望结果：{"jsonrpc":"2.0","id":1,"result":"0x2a5"}   # 0x2a5 = 677 = BOT Chain 主网
