## 1. 这个项目是什么

一句话：**给骑手与沿街商户的参数化降雨险**——保费按「城市 × 12h/24h」定，链上喂入真值雨量，达到国标阈值就自动判定、自动赔付；每一步都能在链上核验。

三个差异化点（对外讲的就是这三条）：

1. **阈值来自国标查表**（GB/T 28592—2012 §3 只有 12h / 24h 两档），不是自定的线性公式 → 见 `10-金融与定价/GB28592-12h24h重建-B给A-2026-10-07.md`。
2. **判定快照**：`Judgement.rainfallAtJudgement` — `claim` 按**判定当时**的读数赔，而不是申请那一刻（防止窗口滚动把该赔的保单磨掉）。
3. **无钱包三步上手**：`buyFor(beneficiary, …)` + `Policy.payer` — 出资人与被保人分离 → 留痕见 `08-截图存证/A6-无钱包三步上手-2026-10-11.md`。

产品/机制文档（按可读性排序）：
- `PRODUCT.md`（根目录）— 产品定义与参数
- `提交材料/项目介绍.md`、`提交材料/产品说明与商业模式.md`、`提交材料/用户与场景.md`
- `02-作战与答辩/产品架构与设计.md`、`02-作战与答辩/架构-险种泛化设计.md`

### 3.5 喂价新鲜度（现场演示的第一杀手）

## 4. 合约与产品机制

### 4.1 版本谱系（为什么三版并存）

| 版本 | 何时 | 关键变化 |
|---|---|---|
| v1 | 10-06 | 最小可用：投保/喂价/判定/索赔 + 池子 |
| v2 | 10-07 | 承保层：档位化（tier）、`aiPremium`、`MAX_POLICIES_PER_RIDER`、48/72h 档、20 笔多签落 15 格网格 |
| v3 | 10-07 夜 → 10-08 部署 | A-5 四件：`MIN_PREMIUM` 降 10×、5 参 `premiumOf` + 可插拔 `pricingModule`（保留 2 参兼容重载）、`hoursAllowed={12,24}` + 国标查表 `thresholdOf(hours,tier)`、判定快照；A-6：`payer`/`buyFor`；另加 `openPoliciesOf`（只计未结清、O(1)）、`settleExpired` 去 `onlyOperator`、`refundPolicy`（冷静期内退保、退款给 payer） |

**为什么 v3 部署在 677 而不重部署 968**：10-07 距提交 19 小时，全部对外证据（8 张存证图、60 秒视频、核验台链接、PPT、哈希清单）都锚在 968 同址上，重部署即全部作废 → 见 `02-作战与答辩/v3-定价-A回B-2026-10-07.md:15`。

### 4.2 v3 关键时序

1. 投保 `buyPolicy`（或 `buyFor`）：付保费 → 记录 `effectiveFrom = now + coolingPeriod`（**259200 s = 3 天**）。
2. 冷静期内可 `refundPolicy` → 退款给 `payer`；退过的保单**不可再判、不可再赔**（`claim` 与 `submitJudgement` 都 `require(!p.settled)`）。
3. operator（= 2/3 多签）`updateRainfall` 喂真值 → `submitJudgement` 写入 `Judgement.rainfallAtJudgement`。
4. `claim` 按**判定快照**的读数赔（不是申请那一刻）。
5. 窗口结束后任何人可 `settleExpired`。

- **成本口径两法**：保守口径 0.00025 → 北京档 **−7.81e-5（亏）**；期望口径 ≈0.000135 → **+3.92e-5（微利）**。骑手端投保手续费 ≈0.00046 ETH **高于北京档保费 0.0004** ⇒ 低价档必须靠批量/代付渠道摊薄（平台代付渠道逐格摊薄倍数实测 **83.7× ~ 325.7×**）。
- **双通道验证**（日粒度 vs 小时粒度）：差异 **0.10 – 0.16 pp**。
- **广州「越线不显著」**：月聚类自举 95% 区间 **[9.35%, 13.88%]** ⇒ 对外不说「广州必然触发」。
- **72h 权威命中数表**（分母 96,361）：武汉 4596 / 4.7696% · 上海 4391 / 4.5568% · 北京 2198 / 2.2810% · 广州 11153 / 11.5742% · 成都 3588 / 3.7235%。
- **`actuary-output.json` 曾与权威值有差**：根因是浮点边界漏计，**唯一确定解 = 放大 10 倍做整数运算**（已在引擎里落地）。
- **Monte Carlo**：`reserve_mc.js` 支持固定种子 `--seed 42`；48/48 恒等式成立，最大绝对差 **1.86e-14**；`_mix_H72_N200` 的 P(当月亏损) = **14.00% – 15.23%** ⇒ **对外说「约 15%」**，不报小数。
- **`max_eth` 不可对外引用**（推导过程中的中间量），可引用 `E_loss` / `P_loss` / `VaR95` / `VaR99`。

### 5.3 数据源与许可

- 雨量：**Open-Meteo Archive API（ERA5）**，许可 **CC BY 4.0** ⇒ 对外必须**署名 + 非商用**。

- 触发：push main / PR / 手动；ubuntu-latest + Node 22；`npm ci` 两遍（**先 `04-脚本` 后 `07-测试工具`**）；然后 `npm test`。

### 7.3 门禁是什么、不是什么

- **是**：任何人换台机器都能复现的「这些话是真的」的证据；CI 里有公开记录。
- **不是**：它只证明**被断言的那些事**。它不跑合约的形式化验证，不覆盖「合约逻辑本身是否合理」。第三轮扫描专门列了**门禁自己的假绿**（见 §12.2）。

## 13. 本机环境与踩坑清单（换机器必读）

1. **依赖两处都要装**：`04-脚本` 与 `07-测试工具` 各一次；`07-测试工具` 的门禁会 `require` `04-脚本` 的模块。
2. **Windows 跑门禁用 `npm.cmd test`**（Git Bash 里 `npm` 可能解析到 shell 脚本失败）。
3. **中文路径**：本仓目录名全是中文。PowerShell 下 `git ls-files | Select-String` 对非 ASCII 路径会给**假结果**；查内容一律用 ripgrep / grep，列文件用 `git -c core.quotePath=false ls-files`。
4. **不要用 `Set-Content -Encoding UTF8`**（会带 BOM）；写文件用编辑器/写入工具。
5. **PowerShell 里不要用 `h` / `H` 当函数名**（与 `Get-History` 别名冲突）。
6. **`Tee-Object` 落盘是 UTF-16LE**，中文会乱码；要留可读日志用 `> file 2>&1` 重定向到 bash 侧，或指定 `-Encoding utf8`。
7. **prot_live.py 之类批改脚本要处理 CRLF**：读入 `src.replace("\r\n","\n")`，写回再 `.replace("\n","\r\n")`。
8. **PowerShell here-string 收尾 `'@` 必须独占一行**，否则 git 报 `pathspec '=' did not match`。
9. **仓库命令必须显式传工作目录**（后台作业尤其）：漏传会落到别的目录，报 `npm error enoent Could not read package.json`。
10. **全局数字检索会误命中 `05-演示站点/ethers.umd.min.js`**（526 KB 单行）—— 数字类检索加 `-- '*.md'` 或用工具过滤。
