## 二、为什么「部署不了」—— 两个卡点，都不是代码问题

1. **Gas = 0（唯一硬阻塞）**。10/7 20:2x 走代理实读 677：`eth_chainId` = 677、块高 **25,846,059**、`eth_gasPrice` = **20 Gwei**、operator `0xb466B1D1fA19026e08C3311C555d220AE2E1Ba3a` 余额 **0 BOT**。手册 `01-赛事资料/handbook_v0.8.txt:168` 说 Gas 由主办方通过**选手群/技术联系人**提供。
2. **网络（可绕过）**。本机**直连** `https://rpc.botchain.ai` 不通（node `fetch failed`；手册同页 `:182` 给了这一条官方 RPC，chainlist 上无公共备用节点，DoH 通道被墙）。
   ⇒ 但**挂 FlClash 代理（`127.0.0.1:7890`）就通**：10/7 20:2x 实测 JSON-RPC 往返 **629 ms**。`scan.botchain.ai` 也返回 HTTP 200 ⇒ 部署后能立刻拿到浏览器链接。
   ⇒ 所以早先那句「677 本机不可达」应更新为：**必须挂代理；挂了就能部署**（`04-脚本/deploy.js:76` 已内建读操作重试 + `:107` `staticNetwork`）。

## 三、为什么「可以部署到真实 BOT Chain」—— 而且这条链更干净

- **968 上真值写不进去**：`03-合约/RainDeliveryInsuranceV2.sol:250` 是 `require(cumulativeMm >= rainfall[regionId], "cumulative must not decrease")`，链上存的是自 2026-10-01 起的**绝对累计值**，而模拟值已经把水位抬高 ⇒ 写真值（武汉 16.3 / 上海 41.7 / 北京 0 / 成都 6.5 mm）必 revert。968 上只能 `npm run push -- --refresh`（同值刷新，只推进 `lastFeedAt`）。
- **677 是全新部署**：`rainfall[]` 从 0 开始 ⇒ **第一条喂价就能用真实数据**（Open-Meteo 真值 + 三模型交叉核验），不需要 `--demo`、不需要同值刷新 ⇒ 主网那份链上留痕的雨量**是真的**。
- **脚本已就绪、且自带认链**：`04-脚本/deploy.js --v2` 用 **chainId + 块高双重确认**（`deploy.js:74` 已知链表、`:117` 注释说明 chainId 可被本地假链伪装所以还要块高），认不出直接抛错、不静默部署；v3 定价模块可选走 `04-脚本/deploy-pricing-v3.js --rpc=https://rpc.botchain.ai --chain=677`（会 assert chainId=677 且块高 ≥ 1,000,000）。

## 六、拿不到 Gas 怎么办（兜底与口径）

- **968 不算「有效部署」**：手册 `:166` 明确「仅报名、创建钱包、**申请 Gas**、领取测试币、**测试网部署**或表达参赛意向，均不计入有效部署项目」；`:190` 要求补 **Mainnet** 区块浏览器链接 + 交易记录 + 合约/应用地址。⇒ 材料里**不要**把 968 写成已达标。
- **可以赛后补**：手册 `:165` 允许数量不足时赛后继续组织，**最迟 2026-11-03**；但**不延长作品提交期限**（`10-08 12:00`）。⇒ 材料写「主网部署能力已就绪，等待主办方 Gas」，并给出 968 演示链 + 就绪脚本作为证据。
- **直通资格不依赖部署**：手册 `:160` 说的是在武汉场完成提交并符合参赛要求即可直通 BOT Chain BUILD BEYOND 2026 全球线上赛 ⇒ 拿不到 gas **不损失直通**（`02-作战与答辩/待解决问题清单-10-07.md` §四 已裁定）。
- **现场网络兜底顺序**：60 秒视频 → 存证截图 → 单文件核验台（`06-核验台单文件/汉客松-链上核验台.html`，它页脚本来就写着「连不上节点时改用仓库里的截图存证」）。
