# 雨证 · 项目合并与精简方案（2026-10-30）

> 目的：把 `汉客松` 下并行的两套结构（`雨证` 产品树 + `保险创业赛-2026` 参赛树）合并成**单一项目 `雨证`**，去掉重复与过期文件，同时保证功能零回退。

## 一、文件与功能对应关系（合并前）

| 位置 | 是什么 | 被谁引用 |
|---|---|---|
| `` | git 仓库根。合约、脚本、演示站点、核验台、测试工具、截图、留痕、定价数据 | 计划任务 3 个、`build-site.js`、`preflight.js`、全部 npm 脚本 |
| `04-脚本/` | feeder / keeper / preflight / 补气 / 部署脚本 | Windows 计划任务 `RainProof-Feed`、`RainProof-Keeper-V6`、`RainProof-OpsDaily`（**动作里是绝对路径**） |
| `05-演示站点/` → `site-dist/` | 构建源 → 构建产物（`.gitignore` 已忽略，可重建） | `07-测试工具/build-site.js`、演示脚本 |
| `_归档/` | 2026-10-13 的 b-probe 渲染图等旧资产 | 无人引用 |
| `提交材料/` | 早期提交文案（20 个 md）+ 2 段演示视频 + 1 份 9.2M 旧 PPT | 文档里偶有提及 |
| `保险创业赛-2026/` | 参赛文案、计划书、答辩/路演 PPT、定价表、deck 生成脚本、历史备份 | `patch-deck.py`、`rmb-pricing.js`、`audit-inventory.py`、`09-现场演示操作脚本` |
| `保险创业赛-2026/02-定价-人民币口径/` | 人民币定价引擎输出与敏感性表 | `rmb-pricing.js` 读 `../../10-金融与定价/pricing-engine.json` |
| `00-赛事资料/` | 主办方原文、纪要、选手手册、录取通知书 | 无人代码引用 |
| `路演与展示/` | 单份 8.8M 路演 PPT1 | 与 `_归档`、`提交材料`、`_history` 中同一文件 **4 份完全相同** |
| `密钥-本地/` | owner 私钥文件 | **11 个脚本**用 `path.join(__dirname, "..", "..", "密钥-本地")` 读取 |

### 结论（决定什么不能动）
1. `密钥-本地` **必须留在项目外**：11 处 `../../密钥-本地` 引用 + 私钥不能进仓库。移进去要改 11 个脚本，且会把私钥放进 git 工作树，风险大于收益。
2. `site-dist/` 是构建产物，删掉用 `node 07-测试工具/build-site.js` 重建 → 不算"删功能"。
3. `04-脚本` 绝对不能在移动后不改计划任务，否则三个任务全部 0x1 静默失败（10-30 已踩过一次）。
