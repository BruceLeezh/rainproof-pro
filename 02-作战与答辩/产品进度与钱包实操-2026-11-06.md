## 4. 本人连接钱包并投保：操作清单

### A. 进入当前入口

打开[骑手保障中心](https://bruceleezh.github.io/rainproof-pro/rider.html)。浏览报价和演示保单无需钱包。使用装有浏览器钱包扩展的 Edge / Chrome，解锁自己的测试账户后点击“连接钱包（测试网 968）”。

网络手动配置：

| 字段 | 数值 |
|---|---|
| 名称 | BOT Chain Testnet |
| 链 ID | `968`，十六进制 `0x3c8` |
| RPC | `https://rpc.bohr.life` |
| 原生币 | `BOT`，18 位精度 |
| 应用配置的浏览器 | `https://scan.bohr.life`；交易核验也可使用项目核验台 |

页面会申请账户权限，必要时申请添加及切换网络。拒绝连接或切网不会完成投保。连接后“我的钱包”地址应与扩展里选中的地址相同；若自己尚未购买，“暂无保单”是正常结果。

### B. 准备两种币

| 币种 | 用途 | 获得方式与验收 |
|---|---|---|
| 测试 BOT | 支付授权、投保以及其他链上操作的手续费 | [官方测试水龙头](https://faucet.botchain.ai/en/basic) 页面提供申请入口；需要地址及验证。以钱包实际到账为准，本轮只核对入口，没有代领 |
| 模拟 RDROP | 支付模拟保费 | 当前 token 的 owner 是 2/3 多签，须由项目运营发放或由已有持币账户转入；普通用户不能自行 mint。提供收款**公开地址**即可，不提供私钥或助记词 |

RDROP 手动导入：合约 `0x23e928922711903607031378005DFe29D9b730bD`，符号 `RDROP`，精度 **2**。导入只是显示已有余额，不是领币。100 链上原始单位 = 1 RDROP 模拟计价单位。

准备金额以所选区划的**当前链上报价**及钱包 gas 估算为准。本轮读回：武汉 12h/24h 分别为 5.90/8.80；广州分别为 5.90/7.90。两档最高给付仍同为 75，门槛及保费不同。不是将 24h 价格简单乘二，也不是把研究版新报价直接用到现行合约。

如果项目方不发 RDROP，当前部署只能从其他持币者取得，不能通过导入、授权、换 RPC 或领 BOT 替代。完全独立运行需要部署自己的测试 token、保险合约和运营流程，属于另一套实例，不会拥有现有保单与池子。

### C. 提交与核对

1. 选区划及 12h / 24h；读清报价、档线及喂价标签。区划喂价过期时先不签名，等待运营恢复或选择数据合格的区划。
2. 默认不勾选“100 份额度”。首次点击投保，一般先确认 **RDROP 授权**；spender 应为当前 V6-T1 合约 `0xD61d4EfF50C3BeFbe555a604280985904Bc00363`，默认额度为本单保费。
3. 授权到账后确认 **投保** 交易。已有足够授权时会跳过前一步。授权成功并不代表保单已生成；必须等投保交易确认。
4. 在“我的保单”核对：本人地址、保单号、区划、时长、实际保费、保障起止时间；展开保单凭证并复制留存。交易失败时按页面错误处理，不重复连点。
5. 先等待购买后的 **24h**，之后进入所选 12/24h 保障。等待期降雨不计入保障增量。展开“保单操作”，在生效后且已有保障期内新喂价时，可点“锚定生效基线”并由钱包确认；已锚定不能重做，保障结束后本页面不提供补锚定。正式判定仍由运营在保障期内完成。
6. 有合格判定时，Keeper 可协助领取；也可在“保单操作”点击“领取赔付”由钱包确认。收款人固定为被保险人，代领账户不会收到赔款。无及时合格判定、未达线、资金不足或已过七天领取宽限时，不能完成领取。
7. 想在生效前退出：在“保单操作”点击“生效前退款”，只有付款人账户且尚未生效时可操作，全额退给付款人。生效之后按钮禁用；七天宽限不是退保窗口。退款或到期结清后的链上状态统一为 `settled`，应结合交易回执核对退款结果。

本轮尚未代替你的浏览器账户完成真实签名。个人实操验收需要记录：钱包地址、BOT/RDROP 到账、授权交易哈希、投保交易哈希、生成的保单号；后续再记录锚定、正式判定及领取结果。不会为了演示而伪造天气达标。

### D. 常见卡点

| 现象 | 排查与下一步 |
|---|---|
| 未检测到钱包 | 在已安装并解锁扩展的钱包浏览器中打开页面；普通内置浏览器未必提供 `window.ethereum` |
| 提示网络不是 968 | 完成钱包加网/切网，再核对链 ID；旧版 README 的 677 属于历史网络说明 |
| BOT 足够仍报余额不足 | 看 RDROP，不是只看 BOT；RDROP 支付保费，BOT 支付 gas |
| 导入 RDROP 后余额仍为 0 | 尚未收到代币；导入不等于 mint 或领币 |
| 授权成功却没保单 | 第二笔投保可能尚未签名、失败或未确认；核对该交易结果 |
| 连接后两张演示单消失 | 页面改查本人地址；演示单并不属于该账户 |
| 暂不可投保/喂价过期 | 数据或风控限制；网页真实/实时对照不会修改链上状态 |
| 页面无法连接 RPC | 检查节点/DNS与网络；只查看已存材料时可使用断网备份 |
