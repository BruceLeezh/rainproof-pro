### 3. keeper 把一次 DNS 抖动记成失败；换错地址则静默停摆

`RainProof-Keeper-V6` 曾报 `0x1`，日志尾部是 `💥 getaddrinfo ENOTFOUND rpc.bohr.life` —— 一次网络抖动让整次运行算失败（计划任务不重试，只能等下个半点）。顺带发现更危险的静默失败面：若 `deployment.json` 的地址指向不存在的合约，`nextPolicyId()` 会解出 0，keeper 就永远打印「链上还没有任何保单」并成功退出。

`04-脚本/keeper.js` 两处改动：

- **容错**：`--once` 走新的 `runOnce()`，扫描失败原地重试一次（5 秒）；仍失败且属传输层错误（`ENOTFOUND`/`EAI_AGAIN`/`ECONNRESET`/`TIMEOUT`/`SERVER_ERROR`…）→ 打印警告并按**退出码 0**结束，交给 30 分钟后的下一轮。最外层 catch 再判一次，因为传输错误也可能发生在扫描之前的准备阶段。V6 有 7 天领取宽限，漏一两轮不会让骑手领不到钱 —— 这是按「跳过」而非「报错」处理的依据。
- **地址探针**：启动时 `provider.getCode(addr) === "0x"` 直接报错退出 1，并指向 `deployment.json`。实测指向 `0x…0001` 时输出「合约地址上没有代码（链 968）」、退出码 1；正常地址不受影响。
- **补一道外部观测**：`preflight.js` 新增 `checkKeeperLog()`，读 `V6-keeper.log` 里最后一条「===== 时间 轮询开始 =====」，超 90 分钟没跑就 ⚠。用 keeper 自己的表头而不是计划任务的 `LastRunTime`，因为后者只证明「启动了」，不证明「跑通了」——任务被禁用、被杀、或卡在 RPC 上都可能留下正常的 LastRunTime。当前 0 张保单时措辞降级为「暂时不致命」。

### 4. keeper 的日志本身是坏的：乱码 + 被杀就丢

`04-脚本/keeper-v6-once.ps1` 原来是 `$output = & node …; $output | Add-Content -Encoding UTF8`，两个毛病：

- node 写 UTF-8，PowerShell 默认按控制台代码页（cp936）解码 → 中文变成「鍚姩」；同一目录还留着一个乱码文件名 `02-浣滄垬涓庣瓟杈‐V6-keeper.log`，就是中文路径被读坏的结果。
- 抓输出会把整轮内容缓冲到进程退出，任务被 Ctrl+C 打断时**一个字都不落盘** —— 恰恰是最需要日志的时候没有。

改为 cmd 层重定向（`node keeper.js --v6 --once --settle >> 日志 2>&1`）：字节直落盘、流式写入、被杀也留下已产出的部分。另外给 `keeper-v6-once.ps1` 与 `ops-daily.ps1` 补回 **UTF-8 BOM**（Windows PowerShell 5.1 读无 BOM 文件按 GBK 解码，中文路径会读坏）并加目录守卫（读坏时 `exit 3` 并说明原因，不静默产垃圾）；`ops-daily.ps1` 顶部加 `[Console]::OutputEncoding = UTF8`，让它抓 `npm test` / `notify.js` 的中文不再乱码。乱码日志归档到 `_归档/日志-乱码作废-V6-keeper-20261029.log`。

### 5. `RainProof-Feed` 的 `0xC000013A` 不是故障

preflight 一直把它当⚠挂着。查明：`0xC000013A` = `STATUS_CONTROL_C_EXIT`，控制台收到 Ctrl+C 或被关闭。翻日志里 6 次 `^C`，**全部紧跟在最后一条 `✅ … executed=true` 之后**，没有一次打断在批次中间（submit 与 confirm 成对出现、笔数对得上）。属收尾噪声。preflight 改为按正常项显示并写明原因，避免「长期红着」把真正的红变成背景色。

### 6. V6 隔离链门禁在忙机器上偶发

`07-测试工具/e2e_v6_review.js`（23 项断言）连跑 7 次失败 2 次，两类环境原因：ganache 的 uws 原生模块被上一次运行的残留进程占住（`Cannot find module '../binaries/uws_win32_x64_137.node'`）、以及一次瞬时 revert。都不是产品逻辑。`package.json` 的 `e2e:v6-review` 与 `e2e:v6` 改为「失败再跑一次」，文件头写明原因 —— 真有回归时两次都会红。
