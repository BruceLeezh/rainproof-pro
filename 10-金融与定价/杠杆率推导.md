## 0. 结论（先给答案）

**杠杆 `L` 不能锚「保本线」，必须由外生目标赔付率 `R*` 反解：**

```
L = R* / p
```

其中 `p` 是该区域在**指定时长窗口**内的触发概率（观测量），`R*` 是承保人设定的**目标赔付率**（决策变量）。我们钉 **`R* = 60%`**。

**72 小时窗口下的应然杠杆：**

| 城市 | p(72h) | **应然杠杆 L=R*/p** | 应然保费 | 链上现价 | 现价对应 L | **现价实际赔付率** |
|---|---:|---:|---:|---:|---:|---:|
| 武汉 | 4.770% | **12.58** | 0.000795 | 0.0008 | 12.5 | **59.6%** |
| 上海 | 4.557% | **13.17** | 0.000760 | 0.0008 | 12.5 | **57.0%** |
| 北京 | 2.281% | **26.31** | 0.000380 | 0.0004 | 25.0 | **57.0%** |
| 广州 | 11.574% | **5.18** | 0.001929 | 0.0020 | 5.0 | **57.9%** |
| 成都 | 3.724% | **16.11** | 0.000621 | 0.0007 | 14.3 | **53.2%** |

> p 为**整数十分位零浮点**口径的权威值（复算 `node derive_metrics.js --self-check`）；推导见 `10-金融与定价/指标推导-变量表.md`。原表为浮点累加口径（4.756/4.557/2.265/11.524/3.719），差 ≤ 0.05pp、结论不变。

> ⚠️ **本段已于 2026-10-07 修正（专家复核发现原表述是过度解读）**
> 原稿写「链上现价的实际赔付率 53.1%–59.5% → 说明 `R* = 60%` 口径**在链上早已被真实执行**」。**这个推断不成立**：该区间是**上整取整规则的数学必然**，不含任何独立证据。
> 证明：保费 = `ceil₄(p × 0.01 / 0.6)`，故 `R = p×0.01 / ceil₄(p×0.01/0.6)` 恒被夹在 `[0.6q/(q+1e-4), 0.6]`（`q = p×0.01/0.6`）→ **偏差完全单侧，五个价格必然都 ≤60%**，换任何 `p` 都会得到同样的区间。反面校验：若用四舍五入而非上整，成都应为 0.0006（链上是 0.0007）→「上整规则」被 5/5 证实，「四舍五入碰巧」被证伪。
> **正确表述**：**保费由 `R* = 60%` 反解、再上整生成；取整后实际赔付率自然落在 53.19%–59.62%。** 这条仍能说明「定价不是拍的」（有反解公式与链上交易哈希），但**不能**说明「链上独立执行了我们设的目标」。
>
> 仍然有效且更硬的一条：`PREMIUM = 0.001 ether` 只是 `03-合约/RainDeliveryInsurance.sol:20` 的**默认值**，`premiumOf()` 实际读 `aiPremium[regionId]`（`:125-128`）。**「10 倍杠杆」不是我们的定价，是没人用的默认值。**

## 1. 为什么不能锚「保本线」

保本条件：

```
p × PAYOUT < PREMIUM   ⟺   p < PREMIUM/PAYOUT = 0.001/0.01 = 10%
```

移项得 `PAYOUT/PREMIUM < 1/p`，即 `L < 1/p`。

**但 `L = 1/p` 是 `R = 100%` 的特例** —— 在这一点上期望赔付恰好等于保费收入，**利润为零、费用为零、安全边际为零**。把它当定价锚点，等于把保险公司经营在破产边界上。

这是**范畴错误**：`L < 1/p` 是**可行域边界（约束）**，不是**目标（解）**。

**保本线的正确用途**：只作**上限告警线**。超过它一定亏（单区域、期望口径）：

| 城市 | 保本上限 `1/p` | 现价 L=10 是否越界 |
|---|---:|---|
| 武汉 | 21.03 | 否 |
| 上海 | 21.95 | 否 |
| 北京 | 44.14 | 否 |
| **广州** | **8.68** | **✅ 越界（10 > 8.68）** |
| 成都 | 26.89 | 否 |

> ⚠️ **本表只管一个已经不存在的场景**：`L = 10` 是**已退役的统一价**（对应链上没人用的默认 `PREMIUM`）。链上现价是**按区域差异化定价**（武汉 0.0008 / 上海 0.0008 / 北京 0.0004 / 广州 0.0020 / 成都 0.0007），对应杠杆 12.5/12.5/25.0/5.0/14.3 —— **五个价格全部在自己区域的保本线内**。
> **对外只讲一句**：「统一杠杆在方案早期被退役，因为广州单城会越界；我们改用按区域反解的差异化定价，链上已经执行。」**不要把「广州必亏」当现状讲** —— 那是旧方案。

## 2. 严谨推导链（每一步的假设都标明）

```
① 杠杆定义       L := PAYOUT / PREMIUM                                    [合同常数，无量纲]
                 假设：PAYOUT、PREMIUM 均为合约常量（.sol L20 PREMIUM / L21 PAYOUT）

② 单份期望赔付   E[loss] = p × PAYOUT                                      [精算公平]
                 假设：p 为该保单在其时长窗口内的触发概率；赔付额恒为 PAYOUT

③ 毛保费分解     PREMIUM = (p × PAYOUT) / R*                               [目标赔付率定价]
                 假设：R* 为承保人外生设定的目标赔付率，需覆盖费用与利润

> ⚠️ **补注（2026-10-11，对齐审计 A11）**：本式是**符号化简写**，链上落地的 v3 正式式在 [`定价逻辑与正收益保障-B-2026-10-07.md`](定价逻辑与正收益保障-B-2026-10-07.md) §4.1：`P_net = ceilTick((E_upper × PAYOUT_MAX + C) / 0.6)`，`C = JUDGE_GAS/N + PAYOUT_GAS × E[f]`。与上式两处差别：① 分子用**上界期望赔付** `E_upper`（`p` 只是它的输入）；② 分子**加上每单链上固定成本 `C`** —— 这正是 `R* = 60%` 之所以是**上限约束**的原因。`R*` 仍为决策变量，本文件其余推导不变。

④ 反解           L = PAYOUT / PREMIUM = R* / p                            ← 唯一有经济含义的杠杆式
```

**三条关系互为等价，没有第四种写法**：

```
保本边界   L < 1/p          （R = 100% 的特例，约束）
赔付率恒等 R = p × L        （观测，不含新信息）
定价反解   L = R* / p       （R* 外生给定，这才是定价式）
```

> ⚠️ **适用限定**：这三式**只在「同一张保单、同一区域、同一时长窗口」内成立**。
> `p` 的分母一换（换窗口长度、换数据粒度、换城市范围），`L` 和 `R` 就**不再可比**。这是本文所有口径风险的源头。

## 3. 为什么「统一杠杆」在结构上不成立

`L` 与 `R` **只有一个是自由变量**：

- **固定 `L = 10`** → `R` 随 `p` 摆动：北京 22.8%、成都 37.2%、武汉 47.7%、上海 45.6%、**广州 115.7%**
- **固定 `R* = 60%`** → `L` 必须在 **5.21 ~ 26.49** 之间摆动

**二者不能同时固定。** 想让 `L` 钉死为 10，就必须接受广州赔到 115%（靠其他城交叉补贴）；想让 `R` 钉死在 60%，`L` 就必须按区域变。链上做的是后者（正确操作）。

### 统一杠杆失效的量化条件

```
单一 L 对全城可行  ⟺  max(p_i) × L ≤ R_max（可接受的最坏赔付率）
广州 p = 11.574%  ⟹  L > 8.64 时广州必亏
```

**现价 L = 10 > 8.64 → 单一杠杆（在单城口径下）已经不成立。** 这是算术，不是判断。

### 但"亏不亏"完全取决于分母

| 口径 | p | L=10 下的 R | 判定 |
|---|---:|---:|---|
| **单城（广州）** | 11.574% | **115.7%** | **亏** |
| **五城等权组合** | 5.381% | **53.8%** | 不亏 |

同一个 `L=10`，**两个口径给出相反结论**。

> **因此对外陈述必须自带分母**：「统一杠杆在**等权组合**下给出 53.8% 赔付率，但**广州单城**是 115.7%、已越过 8.64 的保本线。」

> ⚠️ **本段（连同上面两张表）已于 2026-10-07 限定适用范围**：这里讨论的 `L = 10` 是**已退役的统一价**。**在链上现价下，「投保量集中在广州就会转亏」这句话是错的** —— 五个价格各自对应自己区域的 p，`R = p_i × L_i` 逐城都在 [53.19%, 59.62%] 内，**是 per-region 常数**，因此**任意投保权重组合的赔付率都落在同一条带内**（这就是「混合不变性」）。按现价全押广州，赔付率仍是 **57.9%**。
> **对外请改说**：「统一杠杆的集中度风险是我们**已经解决掉**的问题 —— 现价按区域反解，任何投保权重组合的赔付率都在 53%–60%。反过来，如果当初保留统一价，那么全部投保量集中在广州会把赔付率推到 115%。」这才是能加分的表述。

## 4. 时长维度：「杠杆」是误导性指标

`L` 是合同常数（不随时长变），但 `p(h)` 随窗口强增长 → **同一 `L` 下不同时长的赔付率差近两个数量级**：

**`R = p(h) × 10`（现价 L=10），单位 %：**

| 城市 | 6h | 12h | 24h | 48h | **72h** | 168h |
|---|---:|---:|---:|---:|---:|---:|
| 武汉 | 0.52 | 2.20 | 7.54 | 27.09 | **47.56** | 156.29 |
| 上海 | 0.30 | 1.98 | 7.54 | 23.32 | **45.57** | 154.06 |
| 北京 | 0.31 | 1.17 | 4.38 | 12.72 | **22.65** | 74.24 |
| **广州** | 0.59 | 3.26 | 14.20 | 59.43 | **115.24** | 324.38 |
| 成都 | 0.39 | 1.71 | 5.92 | 20.54 | **37.19** | 117.40 |

**`72h` 与 `6h` 的 p 相差 73–195 倍**（广州最悬殊）。

### 严谨处理

1. **杠杆必须绑定时长下标**，写作 `L_{region, window}`；对外只说 `L(72h)`
2. **讲多时长产品时不用杠杆，改用「赔付率 R(h)」或「每份保单期望赔付」** —— 它们才随时长正确变化
3. **链上实际只存在 72h 一个口径**：`premiumOf(uint8 regionId)` 无时长参数（`.sol:125`），`buyPolicy` 要求 `msg.value == premiumOf(regionId)`（`.sol:134`）→ **理性投保人必选 72h**（期限套利）→ **承保组合的真实 p 就是 72h 列**
4. **不得声称「产品杠杆 10 倍」** —— 那等价于说「所有时长、所有区域风险相同」，与数据直接矛盾

## 5. 行业基准：我们没有找到杠杆基准（这是诚实的否定性结论）

经检索（中英文：参数化险赔付率/杠杆基准、ceiling rate、指数保险杠杆率）：

**未找到任何把「杠杆 / 赔付倍数」作为定价基准的一手规则或学理文献。** 检索到的参数化保险材料（ADB 孟加拉产品表、World Bank 参数化保险报告、a2ii 产品特征、Kerala SDMA 产品表、ASU 论文）**全部使用「保费 = 期望损失」的精算公平定价口径，无一条给出「赔付/保费应取 N 倍」的标准**。

> ⚠️ 这是**有限检索的否定性结论**，不能宣称「学理上绝对没有」。对外应表述为：
> **「我们没有检索到把杠杆作为定价基准的行业规则；行业基准都是赔付率口径。」**

**可引的一手基准只有赔付率口径**：

| 门槛 | 出处 |
|---|---|
| 综合赔付率 **低于 70%** → 认定承保盈利，需计提利润准备金（不得分红/转增资本） | 财政部《农业保险大灾风险准备金管理办法》**第十条**（2014-01-01 施行） |
| 综合赔付率 **超过 75%** → 可动用大灾准备金 | 同上**第十四条** |
| 「24 小时降水量 50.0–99.9mm = 暴雨」 | `GB/T 28592-2012`（中国气象局官网转载） |

出处与原文见 [`P1-18-待核四项-核实记录.md`](../02-作战与答辩/P1-18-待核四项-核实记录.md)。财政部原文链接：<https://iaf.org.cn/news/industry/57293.html>

> **这恰好反证了「参考农险定杠杆」这个问法本身锚错了对象** —— 农险管的是**赔付率**，杠杆只是它的函数 `L = R/p`。
